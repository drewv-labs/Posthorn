📯 Posthorn

A frictionless, terminal-native job board alerting daemon.

Get Started View on GitHub

1. Installation

Posthorn runs on Windows, macOS, and Linux. We recommend installing it as a standalone tool using Astral's uv:

uv tool install posthorn

2. First-Time Setup

You do not need to write any code to use Posthorn. Simply launch the app from your terminal:

posthorn

If this is your first time running the app, Posthorn will automatically launch a secure setup wizard. It will ask for your Discord Webhook URL (or Telegram credentials) and your initial target job title. Once saved, the daemon will instantly begin sweeping the boards and delivering matches to your phone.

Operator's Manual

Once the dashboard is running, you can manage the daemon using the following hotkeys:

Manage Campaigns ( c )
Pause the daemon and open the Campaign Manager. Add or remove job targets on the fly. When you exit, the daemon hot-swaps your new configuration without missing a beat.
Force Sweep ( s )
Bypass the 15-minute resting interval and force the daemon to immediately sweep all connected job boards.

Maintenance

If you ever want to wipe your job discovery history and start fresh without losing your configuration, stop the app (q) and run the developer reset command:

posthorn --dev-reset
